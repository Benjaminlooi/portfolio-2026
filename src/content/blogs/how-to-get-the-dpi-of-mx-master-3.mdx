If Logi Options+ shows your **MX Master 3** pointer speed as a percentage, use the conversion table below as an approximate reference. In the community-reported table, **50% corresponds to about 1,000 DPI** and **75% to about 2,000 DPI**.

The **MX Master 3S** has a separate option: enable its 8K sensor range in Logi Options+ to expose numeric DPI settings. Check which mouse you have before following either method.

## How to Set DPI on the MX Master 3S

1. Open **Logi Options+** and select your **MX Master 3S**.
2. Open **Pointer speed**.
3. Enable **Extend sensor range to 8K DPI**.
4. Choose your DPI using the numeric setting shown by the app.

[Logitech documents this toggle for the MX Master 3S](https://hub.sync.logitech.com/mx-master-3s/post/how-do-i-enable-the-8k-dpi-sensor-on-my-mx-master-3s-DTGpPpuUyjHecHq). The 3S option is separate from the original MX Master 3 percentage table.

## Checking Older Logitech Options Settings on Windows

For the older **Logitech Options** application, u/210000Nmm-2 described another method in the [same community discussion](https://www.reddit.com/r/LogitechG/comments/joshln/mx_master_3_how_to_change_dpi/): inspecting its saved XML profile. This is a historical Windows workaround; the paths below are not verified for current Logi Options+ releases.

1. Open `%appdata%/Logishrd/LogiOptions` in File Explorer.
2. Open `apptable.xml` in a text editor and find the application profile you want to inspect.
3. Copy that profile's `<id>` value.
4. Look under `devices/` for the mouse's directory, then open its `Profiles/` directory.
5. Open the XML file whose name matches the profile ID and search for `defaultDPI` or `name="sensor"`.

The original example contained this sensor entry:

```xml
<params>
  <param name="sensorCount" value="1" />
  <param cur="1150" defaultDPI="1000" minDPI="200" maxDPI="4000" stepDPI="50" name="sensor" value="0" />
</params>
```

In that example, `cur="1150"` identifies the saved sensor setting. Read the file without editing it. If the directory or fields are missing, do not assume this workaround applies to your installation.

## Why Does the Same DPI Feel Different?

[DPI is only one part of pointer behavior](https://secure.logitech.com/en-au/discover/a/change-mouse-sensitivity). When comparing settings, also check the operating system's pointer-speed and acceleration settings and whether you selected a different application profile. Use the table as a starting point, then compare with the same software settings.
